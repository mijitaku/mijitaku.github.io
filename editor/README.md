# 身仕度 組版室

`index.html` を配信する静的な編集アプリです。ビルドや外部APIは不要です。フォント・PDF生成・画像変換もこのフォルダーに含みます。

## 保存と移行

- 「＋ PDF」で提出済みPDFを作品ごと取り込めます。1作品25MB・100ページ、全体300ページまで。元のページ順を維持し、作品単位で並べ替えます。
- PDF作品のタイトルと作者名は一覧・目次用です。元PDFの本文は編集しません。プレビューとWebPには2400px長辺の画像を使い、完成PDFには原則として元PDFのページ内容を埋め込みます（注釈・フォーム付きページは画像化）。
- 自動保存・編集データJSONには元PDFとプレビュー画像も含まれます。大きなPDFは保存容量に注意してください。
- PDF読込はMozilla PDF.js 5.4.624（Apache-2.0）を同梱。関連ライセンスはassets/pdfjs-*にあります。

- 編集すると、この端末・ブラウザ・URLの下書きが自動保存されます。次回、同じURLを開くと復元されます。
- 「編集データを保存」でJSONをダウンロードしてください。原稿、画像、並び順、目次、設定、読み込んだフォントを含みます。
- 別の端末やURLへ移るときは「編集データを読み込む」でそのJSONを選びます。
- ブラウザのデータ削除やプライベートブラウズでは下書きが失われることがあります。大事な号は編集データも別途保存してください。
- PDFとサイト用画像は完成誌面です。再編集にはJSONが必要です。

## 維持・移設

このフォルダー全体を保管すれば、別の静的Webサーバーでも公開できます。各ファイルの相対位置を維持し、HTTPSで配信してください。`assets` に同梱したライセンスも一緒に保管してください。

原稿や編集データはサーバーへ送信しません。共有する場合は、利用者がファイルとして渡します。
